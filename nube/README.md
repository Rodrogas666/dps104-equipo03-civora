# Servicio en la nube

Reglas de seguridad, esquema de datos y plantilla de variables del servicio elegido (Firebase o Supabase) para Fases 3 y 4.

- Colecciones/tablas previstas: usuarios, reportes, comentarios de seguimiento.
- Las claves reales van en `.env` (ignorado por Git). Solo se versiona `.env.example`.
- Nunca subir `google-services.json`, `GoogleService-Info.plist` ni cuentas de servicio.
