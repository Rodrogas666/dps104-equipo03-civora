# Prototipo web (Lab Fase 1)

Práctica de laboratorio de la Fase 1 del proyecto **Civora**: lista de reportes comunitarios con tarjetas por reporte. Ya fue calificada y se conserva como referencia; el producto final es la app móvil en `../app-movil`.

## Tecnologías

Next.js 16, React 19, TypeScript, Tailwind CSS 4.

## Instalación

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Estructura

- `src/app/` — páginas y layout
- `src/components/` — `ReporteCard`, `ListaReportes`, `TarjetaReporte`
- `src/types/Reporte.ts` — tipo del reporte
